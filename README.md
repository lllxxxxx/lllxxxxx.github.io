# Xing Li's homepage

Live at https://lllxxxxx.github.io

The whole site is one file: `homepage/index.html`. Edit it on GitHub and commit; the
`Deploy homepage` workflow (`.github/workflows/pages.yml`) publishes it to GitHub Pages
within a minute or two.

- Bio, news, research interests and publications are plain HTML sections in that file.
- To add a photo, upload it as `homepage/photo.jpg` and follow the comment above the "XL" placeholder.

The other files in this repository come from the al-folio template used for the first
version of the site. They are no longer built or published.
